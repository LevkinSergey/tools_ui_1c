# Open Graph Image для Универсальные инструменты 1С

Это изображение будет отображаться при публикации ссылок на сайт в социальных сетях и мессенджерах (Telegram, WhatsApp, Facebook, LinkedIn, VK и др.).

## Требования к изображению

| Параметр | Значение |
|----------|----------|
| **Размер** | 1200×630 пикселей (соотношение 1.91:1) |
| **Формат** | PNG (рекомендуется) или JPG |
| **Размер файла** | до 1 МБ |
| **Цветовое пространство** | sRGB |

## Рекомендации по дизайну

### Обязательные элементы:
1. **Заголовок**: "Универсальные инструменты 1С"
2. **Подзаголовок**: "30+ инструментов для разработчика 1С:Предприятие"
3. **Логотип**: логотип проекта (из `img/logo.svg`)
4. **Фон**: градиент или сплошной цвет в стиле проекта

### Опциональные элементы:
- Иконки инструментов (🔧 💻 📊)
- Ключевые преимущества: "Бесплатно", "Открытый код", "БСП"
- URL сайта: toolc.ru

## Как создать изображение

### Вариант 1: Figma
1. Создайте фрейм 1200×630 px
2. Добавьте градиентный фон
3. Разместите логотип и текст
4. Экспортируйте как PNG

### Вариант 2: Canva
1. Откройте Canva.com
2. Создайте дизайн "Facebook Post" (1200×630)
3. Используйте шаблон или создайте с нуля
4. Скачайте как PNG

### Вариант 3: GIMP/Photoshop
1. Создайте новый документ 1200×630 px
2. Добавьте слои для фона, текста, логотипа
3. Экспортируйте как PNG-24

## Проверка

После добавления файла проверьте отображение:

- **Facebook**: https://developers.facebook.com/tools/debug/
- **Twitter**: https://cards-dev.twitter.com/validator
- **LinkedIn**: https://www.linkedin.com/post-inspector/
- **Telegram**: отправьте ссылку в Telegram (обновляется кэш)

## Инструкция по замене

1. Сохраните новое изображение как `og-image.png`
2. Положите в папку `static/img/`
3. Пересоберите сайт: `npm run build`
4. Проверьте через инструменты выше
