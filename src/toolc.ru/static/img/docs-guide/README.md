# Папка для скриншотов документации

В эту папку следует добавлять скриншоты для руководства по документации.

## Как добавить скриншот

1. Сделайте скриншот:
   - **Windows**: `Win+Shift+S` или `PrintScreen`
   - **Linux**: `PrintScreen` или `Shift+PrintScreen`
   - **macOS**: `Shift+Cmd+4`

2. Сохраните в эту папку с именем в формате: `название-скриншота.png`

3. Откройте файл `how-to-add-documentation.md` и замените заглушки:

   **Было:**

   ```markdown
   :::info Скриншот 1

   > _Здесь будет скриншот папки `instruments` в проводнике файлов_
   > :::
   ```

   **Стало:**

   ```markdown
   ![Пример структуры папки instruments](/img/docs-guide/instruments-folder.png)
   ```

## Требования к скриншотам

- **Формат**: PNG (предпочтительно) или JPG
- **Разрешение**: 1920×1080 или меньше
- **Размер**: до 500 КБ (по возможности)
- **Качество**: четкий текст, хорошо читаемый
- **Язык интерфейса**: русский

## Примечание

В текущей версии документации вместо скриншотов используются текстовые заглушки в блоках `:::info`. После добавления изображений замените эти блоки на стандартный синтаксис Markdown:

```markdown
![Описание скриншота](/img/docs-guide/имя-файла.png)
```
