# Введение

**Универсальные инструменты 1С** — это набор внешних обработок и расширений для платформы 1С:Предприятие 8.3, содержащий более 30 инструментов для разработки, администрирования и отладки конфигураций.

## Возможности

- **30+ инструментов** для разработки и администрирования
- **Поддержка БСП** — интеграция с библиотекой стандартных подсистем
- **Открытый код** — лицензия GNU GPL v3.0
- **Кроссплатформенность** — Windows, Linux

## Быстрый старт

1. Скачайте последнюю версию с [GitHub Releases](https://github.com/cpr1c/tools_ui_1c/releases/latest)
2. Подключите расширение к вашей конфигурации
3. Изучите [список инструментов](/docs/instruments/overview)
