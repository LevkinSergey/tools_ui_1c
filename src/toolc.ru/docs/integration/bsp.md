# Интеграция с БСП

Проект поддерживает интеграцию с [Библиотекой стандартных подсистем (БСП)](https://its.1c.ru/db/bsp), что позволяет использовать инструменты непосредственно из форм и списков объектов вашей конфигурации.

## Отладка внешних обработок БСП

Подробное описание в разделе [Отладка внешних обработок БСП](https://github.com/cpr1c/tools_ui_1c/wiki/Отладка-внешних-обработок-БСП).

## Подключаемые команды

В списки и формы объектов добавляется подменю **«Инструменты»**, которое содержит следующие команды:

### Добавить к сравнению

Добавляет выделенные объекты к сравнению для дальнейшего использования в инструменте [«Сравнение объектов»](/docs/instruments/object-compare).

**Доступно:** В списках объектов

### Редактировать объект

Открывает текущий объект в [редакторе реквизитов](/docs/instruments/object-editor). Позволяет выполнять низкоуровневое редактирование.

**Доступно:** В формах объектов

### Сравнить объекты

Открывает инструмент [«Сравнение объектов»](/docs/instruments/object-compare) с выделенными ссылками в качестве объектов сравнения.

**Доступно:** Только в списках

### Найти ссылки на объект

Открывает инструмент [«Поиск ссылок на объект»](/docs/instruments/object-links) для текущего объекта.

**Доступно:** В формах и списках объектов

### Выгрузить объекты в XML

Выполняет выгрузку выбранных объектов с подчиненными ссылками с использованием инструмента [«Выгрузка загрузка XML»](/docs/instruments/xml-exchange).

**Доступно:** В списках объектов

## Требования к подключению

Для работы подключаемых команд необходимо:

1. Объект должен быть подключен к подсистеме `ПодключаемыеКоманды`
2. Форма должна поддерживать расширение команд
3. Расширение «Универсальные инструменты» должно быть подключено к конфигурации

## Подсистемы проекта

Проект содержит следующие подсистемы:

| Подсистема | Назначение |
|------------|------------|
| `ПодключаемыеКоманды` | Добавление команд в формы и списки БСП |
| `Администрирование` | Административные функции |
| `ОтчетыИОбработки` | Группа отчетов и обработок |
| `ИнструментыРазработки` | Инструменты для разработчиков |
| `Интеграция` | Компоненты интеграции |

[Подробнее о подсистемах](/docs/integration/subsystems)
