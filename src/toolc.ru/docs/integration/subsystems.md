# Подсистемы проекта

Проект реализован в формате 1C:EDT и содержит несколько подсистем, которые можно подключать к своим формам и модулям.

## Структура подсистем

Проект реализован в формате 1C:EDT. Исходники находятся в каталоге `src/Инструменты/src/Subsystems/`:

```
src/Инструменты/src/Subsystems/
├── ПодключаемыеКоманды
├── Администрирование
├── ОтчетыИОбработки
├── ИнструментыРазработки
└── Интеграция
```

## ПодключаемыеКоманды

**Имя:** `ПодключаемыеКоманды`  
**Путь:** `src/Инструменты/src/Subsystems/ПодключаемыеКоманды`

Предназначена для добавления команд инструментов в формы и списки объектов БСП.

### Состав подсистемы

- Общие команды
- Команды формы
- Команды списка

### Использование

Для подключения команды к вашей форме:

1. Добавьте подсистему `ПодключаемыеКоманды` в вашу конфигурацию
2. В форме объекта добавьте команду из состава подсистемы
3. Настройте видимость и доступность команды

## Администрирование

**Имя:** `Администрирование`  
**Путь:** `src/Инструменты/src/Subsystems/Администрирование`

Содержит административные функции и инструменты.

### Состав

- Удаление помеченных объектов
- Регистрация изменений для обмена
- Структура хранения базы данных

## ОтчетыИОбработки

**Имя:** `ОтчетыИОбработки`  
**Путь:** `src/Инструменты/src/Subsystems/ОтчетыИОбработки`

Группирует все отчеты и обработки проекта.

### Состав

- Консоль запросов
- Консоль отчетов
- Консоль кода
- И другие инструменты

## ИнструментыРазработки

**Имя:** `ИнструментыРазработки`  
**Путь:** `src/Инструменты/src/Subsystems/ИнструментыРазработки`

Инструменты для разработчиков 1С.

### Состав

- Консоль кода
- Консоль запросов
- Редактор СКД
- Отладка объектов

## Интеграция

**Имя:** `Интеграция`  
**Путь:** `src/Инструменты/src/Subsystems/Интеграция`

Компоненты для интеграции с внешними системами и БСП.

### Состав

- Коннектор HTTP
- Библиотека сериализации
- Универсальный обмен XML
