# Количество объектов в базе

Инструмент для подсчета количества записей в таблицах справочников, документов, независимых регистров сведений и т.п.

## Возможности

- Подсчет количества объектов
- Группировка по типам
- Отбор по организации
- Для периодических объектов - отбор по периоду

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
