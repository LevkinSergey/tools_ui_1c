# Просмотр значения

Инструмент для просмотра значений и их свойств произвольных типов. Позволяет исследовать любой объект по аналогии с диалогом «Вычислить выражение» отладчика.

## Возможности

- Просмотр свойств объекта
- Навигация по вложенным объектам
- Информация о типах
- Копирование значений

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
