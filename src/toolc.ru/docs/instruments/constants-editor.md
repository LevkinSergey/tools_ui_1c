# Редактор констант

Инструмент для редактирования значений констант в режиме таблицы. Позволяет быстро изменять значения нескольких констант одновременно.

## Возможности

- Просмотр всех констант
- Редактирование в табличном режиме
- Массовое изменение
- Фильтрация и поиск

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
