# Консоль HTTP запросов

Инструмент для выполнения HTTP запросов из 1С. Позволяет тестировать API, отправлять и получать данные в различных форматах.

## Возможности

- Выполнение запросов всех методов HTTP (GET, POST, PUT, DELETE, PATCH)
- Настройка заголовков запроса
- Работа с телом запроса (JSON, XML, текст)
- Просмотр ответа в различных форматах
- Сохранение истории запросов
- Поддержка аутентификации

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент, Web-клиент (частично)

## Использование

### Запуск

1. Откройте обработку «Консоль HTTP запросов»
2. Выберите метод HTTP
3. Введите URL запроса
4. Настройте заголовки и тело запроса
5. Нажмите «Выполнить»

### Пример GET запроса

```bsl
Соединение = Новый HTTPСоединение("api.github.com");
Запрос = Новый HTTPЗапрос("/users/octocat");
Ответ = Соединение.Получить(Запрос);

Если Ответ.КодСостояния = 200 Тогда
    ЧтениеJSON = Новый ЧтениеJSON(Ответ.ПолучитьТелоКакПоток());
    // Обработка ответа
КонецЕсли;
```

### Пример POST запроса с JSON

```bsl
Данные = Новый Структура();
Данные.Вставить("name", "repo");
Данные.Вставить("private", Ложь);

ЗаписьJSON = Новый ЗаписьJSON();
ЗаписьJSON.УстановитьСтроку();
ЗаписьJSON.Записать(Данные);
ТелоЗапроса = ЗаписьJSON.ЗакрытьИПолучитьСтроку();

Запрос = Новый HTTPЗапрос();
Запрос.УстановитьТелоИзСтроки(ТелоЗапроса, КодировкаТекста.UTF8);
Запрос.Заголовки.Вставить("Content-Type", "application/json");
```

```bsl

```
