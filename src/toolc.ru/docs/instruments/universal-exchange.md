# Универсальный обмен данными в формате XML

Выгрузка и загрузка данных по правилам обмена. Форк стандартной обработки от 1С с дополнительными возможностями.

## Возможности

- Обмен по правилам конвертации
- Фильтрация выгружаемых объектов
- Прямая выгрузка через HTTP сервис
- Настройка параметров обмена

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
