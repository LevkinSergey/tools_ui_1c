# Редактор JSON

Инструмент для удобного редактирования строк JSON. Содержит подсветку синтаксиса JSON, редактирование в виде дерева, автоподстановки. Редактор реализован на основании библиотеки [jsoneditor](https://github.com/josdejong/jsoneditor).

## Возможности

- Подсветка синтаксиса JSON
- Древовидное представление данных
- Редактирование в режиме текста и дерева
- Валидация JSON
- Форматирование и минификация
- Поиск и замена
- Импорт/экспорт файлов

## Требования

- Платформа 1С: 8.3.14+ (для Windows)
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку «Редактор JSON» в списке инструментов
2. Вставьте JSON строку или загрузите файл
3. Редактируйте в удобном режиме (текст или дерево)
4. Сохраните результат

### Пример работы

```bsl
// Пример JSON для редактирования
{
    "name": "Документ",
    "number": "0000-000001",
    "date": "2024-01-15",
    "items": [
        {
            "product": "Товар 1",
            "quantity": 10,
            "price": 100.00
        }
    ]
}
```
