# Редактор прототипов форм

Инструмент для построения прототипов форм в интерактивном режиме. Позволяет быстро накидать внешний вид формы.

## Возможности

- Интерактивное построение форм
- Библиотека элементов управления
- Предварительный просмотр
- Экспорт прототипа

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
