# Консоль веб-сервисов

Обработка для чтения и выполнения веб-сервисов на платформе 1С: Предприятие 8.3. Аналог soapUI. Позволяет выполнить операцию веб-сервиса и отобразить результат в виде XML или дерева.

## Возможности

- Чтение описания веб-сервиса
- Выполнение операций веб-сервиса
- Просмотр результата в виде XML
- Просмотр результата в виде дерева
- Настройка параметров запроса

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
