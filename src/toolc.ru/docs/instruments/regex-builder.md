# Конструктор регулярных выражений

Инструмент для построения сложно-структурированных регулярных выражений на основе параметрического описания, тестирования их и получения программного кода 1С.

## Возможности

- Конструирование регулярных выражений
- Параметрическое описание
- Тестирование выражений
- Генерация кода 1С
- Библиотека шаблонов

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент
- ОС: Windows

## Известные ограничения

- Работает только в Windows
