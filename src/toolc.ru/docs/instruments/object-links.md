# Поиск ссылок на объект

Инструмент для поиска ссылок на объект в базе данных. Аналог стандартной обработки из меню «Все функции».

## Возможности

- Поиск ссылок на объект
- Выбор области поиска
- Группировка результатов
- Переход к найденным объектам

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
