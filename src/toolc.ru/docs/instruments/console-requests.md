# Консоль запросов

Инструмент для разработки, тестирования и выполнения запросов к базе данных 1С. Позволяет выполнять запросы с подсветкой синтаксиса, работать с параметрами и анализировать результаты.

## Возможности

- Выполнение запросов с подсветкой синтаксиса
- Просмотр результатов в табличном виде
- Работа с параметрами запроса
- Сохранение и загрузка запросов
- Анализ плана выполнения
- Поддержка менеджеров временных таблиц

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент, Web-клиент (частично)

## Использование

### Запуск

1. Откройте обработку «Консоль запросов» в списке инструментов
2. Введите текст запроса в редактор кода
3. Нажмите «Выполнить» или клавишу F5
4. Результаты отобразятся в табличном документе

### Пример запроса

```bsl
ВЫБРАТЬ
    Номенклатура.Ссылка,
    Номенклатура.Наименование,
    Номенклатура.Артикул
ИЗ
    Справочник.Номенклатура КАК Номенклатура
ГДЕ
    Номенклатура.ЭтоГруппа = ЛОЖЬ
    И Номенклатура.ЭтоНоменклатурнаяГруппа = ЛОЖЬ
```

### Работа с параметрами

```bsl
&НаКлиенте
Процедура ВыполнитьЗапрос()
    Запрос = Новый Запрос;
    Запрос.Текст = 
        "ВЫБРАТЬ
        |    Номенклатура.Наименование
        |ИЗ
        |    Справочник.Номенклатура КАК Номенклатура
        |ГДЕ
        |    Номенклатура.Ссылка В &СписокНоменклатуры";
    
    Запрос.УстановитьПараметр("СписокНоменклатуры", МассивНоменклатуры);
    Результат = Запрос.Выполнить();
КонецПроцедуры
```

## Программный интерфейс

Инструмент поддерживает отладку через форму вычисления выражения:

```bsl
УИ_._От(Запрос, "Мой запрос")
```

[Подробнее об отладке](/docs/api/debug-api)

## Известные ограничения

- В Web-клиенте некоторые функции могут быть недоступны
- Для работы с большими объемами данных рекомендуется использовать толстый клиент
