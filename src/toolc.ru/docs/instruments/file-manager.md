# Файловый менеджер

Инструмент для удобной работы с файлами между клиентом и сервером. Поддерживает передачу, просмотр и удаление файлов.

## Возможности

- Передача файлов между клиентом и сервером
- Просмотр содержимого файлов
- Удаление файлов
- Работа с каталогами

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Известные ограничения

- Содержит синхронные вызовы
- Требуется право на работу с файловой системой
