# Групповая обработка справочников и документов

Инструмент для массовой обработки данных в справочниках и документах. Аналог типовой обработки от 1С с диска ИТС.

## Возможности

- Массовое изменение реквизитов
- Обработка по отбору
- Пакетное выполнение операций
- Протокол выполнения
- Поддержка различных типов объектов

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку в списке инструментов
2. Выберите тип объектов для обработки
3. Настройте отбор
4. Выберите операцию для выполнения
5. Запустите обработку
