# Структура хранения базы данных

Инструмент для просмотра структуры хранения базы данных: имен таблиц, их взаимосвязей с объектами метаданных.

## Возможности

- Просмотр таблиц базы данных
- Отображение связей с метаданными
- Поиск по таблицам
- Информация о размерах таблиц

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку в списке инструментов
2. Выберите объект метаданных или таблицу
3. Просмотрите информацию о структуре
