# Поиск и удаление дублей

Инструмент для поиска и удаления дублирующихся объектов в базе данных. Форк стандартной обработки из БСП с расширенными параметрами выполнения замены.

## Возможности

- Поиск дублей по различным критериям
- Настройка правил сравнения
- Пакетная обработка
- Протокол выполнения
- Расширенные параметры замены

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку в списке инструментов
2. Выберите тип объектов для поиска
3. Настройте критерии сравнения
4. Запустите поиск
5. Просмотрите результаты и выберите действия
