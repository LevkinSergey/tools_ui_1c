# Консоль сравнения данных

Инструмент для сравнения данных, полученных из разных источников: информационных баз 1С 8, 1С 7.7, баз данных SQL, файлов формата CSV/TXT/DBF/XLS/DOC/XML, строки JSON, вручную заполненного табличного документа.

## Возможности

- Сравнение данных из различных источников
- Поддержка множественных форматов
- Визуальное отображение различий
- Настройка правил сравнения

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
