# Удаление помеченных объектов

Инструмент для удаления помеченных объектов из базы данных. Адаптированная версия стандартной обработки из БСП для жизни вне БСП.

## Возможности

- Удаление помеченных объектов
- Выборочное удаление по типам
- Протокол удаления
- Проверка ссылок перед удалением

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку в списке инструментов
2. Выберите типы объектов для удаления
3. Запустите удаление
4. Просмотрите протокол
