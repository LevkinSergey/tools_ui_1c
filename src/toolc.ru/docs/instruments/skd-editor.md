# Редактор СКД

Аналог конструктора схемы компоновки данных для тонкого клиента. Позволяет создавать и редактировать схемы компоновки данных без использования толстого клиента.

## Возможности

- Создание и редактирование схем компоновки данных
- Настройка наборов данных
- Определение полей и параметров
- Настройка группировок и отборов
- Предварительный просмотр результатов
- Сохранение и загрузка схем

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент, Web-клиент (частично)

## Использование

### Запуск

1. Откройте обработку «Редактор СКД» в списке инструментов
2. Загрузите существующую схему или создайте новую
3. Настройте наборы данных и поля
4. Сохраните схему

### Пример создания схемы

```bsl
Схема = Новая СхемаКомпоновкиДанных;

// Добавление набора данных
НаборДанных = Схема.НаборыДанных.Добавить();
НаборДанных.Имя = "Номенклатура";
Запрос = Новый Запрос;
Запрос.Текст = "
    |ВЫБРАТЬ
    |    Номенклатура.Ссылка,
    |    Номенклатура.Наименование,
    |    Номенклатура.Артикул
    |ИЗ
    |    Справочник.Номенклатура КАК Номенклатура";
НаборДанных.Запрос = Запрос;

// Добавление поля
Поле = НаборДанных.Поля.Добавить();
Поле.Имя = "Наименование";
Поле.ПутьКДанным = "Номенклатура.Наименование";
```

## Известные ограничения

- Не поддерживает редактирование макетов
- Вложенные схемы компоновки требуют дополнительного тестирования
- Некоторые функции доступны только в толстом клиенте
