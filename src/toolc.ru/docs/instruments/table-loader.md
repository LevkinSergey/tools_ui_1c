# Загрузка данных из табличного документа

Инструмент для загрузки данных в справочники и табличные части различных объектов из табличного документа.

## Возможности

- Загрузка из табличного документа
- Настройка соответствия полей
- Обработка ошибок загрузки
- Протокол загрузки

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
