# Консоль кода

Инструмент для выполнения произвольного кода 1С непосредственно из предприятия без необходимости создания внешних обработок. Содержит подсветку синтаксиса и минимальную контекстную подсказку.

## Возможности

- Выполнение произвольного кода 1С
- Подсветка синтаксиса встроенного языка
- Контекстная подсказка
- Сохранение сниппетов кода
- История выполнения
- Поддержка различных режимов запуска

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку «Консоль кода» в списке инструментов
2. Введите код в редактор
3. Нажмите «Выполнить» или F5

### Пример кода

```bsl
// Пример простого кода
Массив = Новый Массив;
Для i = 1 По 10 Цикл
    Массив.Добавить(i * i);
КонецЦикла;

Сообщить("Сумма квадратов: " + Сумма(Массив));
```

### Работа с объектами базы

```bsl
// Получение списка документов
Выборка = Документы.РеализацияТоваровУслуг.Выбрать();
Пока Выборка.Следующий() Цикл
    Сообщить(Выборка.Номер + " от " + Выборка.Дата);
КонецЦикла;
```

## Известные ограничения

- Требуется соответствующее право на выполнение кода
- В Web-клиенте функциональность ограничена
