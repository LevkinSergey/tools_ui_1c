# Конструктор представлений ЗУП

Инструмент для интерактивного формирования представлений, доступных в рамках подсистемы «Зарплата и Кадры».

## Возможности

- Конструирование представлений
- Интерактивный режим
- Поддержка подсистемы ЗУП
- Сохранение результатов

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
