# Менеджер открытых форм

Обработка перехватывает все открытые окна, собирает информацию о формах, выводит её в редактор и позволяет выполнять различные манипуляции. Также позволяет открывать новые окна (в т.ч. системные формы).

## Возможности

- Просмотр всех открытых форм
- Информация о параметрах форм
- Закрытие форм
- Открытие новых форм
- Системные формы

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
