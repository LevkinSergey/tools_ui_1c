# Навигатор по конфигурации

Обработка для навигации по конфигурации. Замена стандартному меню «Все функции» с дополнительными административными функциями.

## Возможности

- Навигация по объектам конфигурации
- Быстрый поиск объектов
- Административные функции
- Избранные объекты

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку в списке инструментов
2. Выберите раздел конфигурации
3. Перейдите к нужному объекту
