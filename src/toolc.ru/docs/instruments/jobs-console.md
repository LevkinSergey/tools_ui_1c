# Консоль заданий

Инструмент для просмотра и настройки регламентных и фоновых заданий. Позволяет управлять расписанием, параметрами и состоянием заданий.

## Возможности

- Просмотр всех регламентных заданий
- Настройка расписания выполнения
- Управление параметрами заданий
- Просмотр истории выполнения
- Запуск и остановка заданий
- Мониторинг состояния

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку «Консоль заданий» в списке инструментов
2. Выберите задание из списка
3. Настройте параметры и расписание
4. Сохраните изменения

### Пример настройки расписания

```bsl
// Получение задания
Задание = РегламентныеЗадания.НайтиПоНаименованию("ОбменДанными");

// Настройка расписания
Расписание = Задание.Расписание;
Расписание.ВремяНачала = Время(8, 0, 0);
Расписание.ПериодПовтора = 3600; // 1 час
```
