# Редактор HTML

Инструмент для быстрой отладки отображения HTML страниц в 1С. Представляет собой экран, разбитый на 4 части: в левой части три редактора (HTML, CSS и JavaScript), а справа — поле результата. Есть контекстная подсказка и автодополнение кода.

## Возможности

- Редактирование HTML, CSS, JavaScript
- Предварительный просмотр результата в реальном времени
- Контекстная подсказка кода
- Автодополнение кода
- Подсветка синтаксиса
- Сохранение проектов

## Требования

- Платформа 1С: 8.3.14+ (для Windows)
- Режим: Толстый клиент, Тонкий клиент

## Использование

### Запуск

1. Откройте обработку «Редактор HTML» в списке инструментов
2. Введите HTML код в левый верхний редактор
3. При необходимости добавьте CSS и JavaScript
4. Результат отобразится в правой панели

### Пример HTML

```html
<!DOCTYPE html>
<html>
<head>
    <style>
        .hello {
            color: blue;
            font-size: 24px;
        }
    </style>
</head>
<body>
    <div class="hello">Привет, 1С!</div>
    <script>
        console.log('Hello from 1C HTML Editor');
    </script>
</body>
</html>
```

## Исходный проект и лицензия

- **Библиотека редактора:** [Ace Editor](https://ace.c9.io/)

## Известные ограничения

- Работает только в Windows начиная с платформы 8.3.14
- Отображение в 1С и браузере может отличаться
- Требуется наличие встроенного браузера
