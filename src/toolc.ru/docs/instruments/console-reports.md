# Консоль отчетов

Переработанная консоль компоновок данных с диска ИТС. Улучшенный интерфейс и дополнительные возможности для работы с отчетами в тонком клиенте.

## Возможности

- Создание и редактирование отчетов СКД
- Настройка параметров и полей отчета
- Предварительный просмотр результатов
- Сохранение настроек отчета
- Работа с вариантами отчетов
- Экспорт результатов в различные форматы

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент, Web-клиент (частично)

## Использование

### Запуск

1. Откройте обработку «Консоль отчетов» в списке инструментов
2. Загрузите схему компоновки данных или создайте новую
3. Настройте параметры отчета
4. Сформируйте отчет

### Пример настройки отчета

```bsl
// Программное создание схемы компоновки
Схема = Новая СхемаКомпоновкиДанных;
НаборДанных = Схема.НаборыДанных.Добавить();
НаборДанных.Имя = "ОсновнойНабор";
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ Номенклатура.Наименование ИЗ Справочник.Номенклатура";
НаборДанных.Запрос = Запрос;
```

## Программный интерфейс

Поддерживается отладка через форму вычисления выражения:

```bsl
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД)
```

[Подробнее об отладке](/docs/api/debug-api)

## Известные ограничения

- Не поддерживает редактирование макетов в тонком клиенте
- Вложенные схемы компоновки требуют дополнительного тестирования
