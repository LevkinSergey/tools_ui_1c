# Сравнение объектов

Инструмент для сравнения ссылочных объектов по реквизитам с выводом результатов в табличный документ.

## Возможности

- Сравнение объектов по реквизитам
- Вывод различий в табличный документ
- Сравнение нескольких объектов
- Настройка параметров сравнения

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
