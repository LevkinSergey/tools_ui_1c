# Динамический список

Инструмент для удобного просмотра списков таблиц базы из одной обработки.

## Возможности

- Просмотр данных таблиц
- Настройка отборов
- Сортировка данных
- Экспорт результатов

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
