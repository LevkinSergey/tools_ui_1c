# Выгрузка загрузка XML с фильтрами

Инструмент для выгрузки и загрузки данных в формате XML. Перенос информации между однородными базами данных с возможностью наложения фильтров.

## Возможности

- Выгрузка данных в XML
- Загрузка данных из XML
- Настройка фильтров выгрузки
- Выбор объектов для выгрузки

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
