# Информация о лицензиях 1С

Инструмент для просмотра информации о лицензиях 1С. Представляет собой обертку функций Утилиты лицензирования 1С (ring) в понятном для обычного человека виде. По сути, это GUI утилиты RING.

## Возможности

- Просмотр информации о лицензиях
- Информация о ключах защиты
- Данные о программных лицензиях
- Отчет о лицензиях

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
- **Необходима установленная утилита ring и ее модули license**
