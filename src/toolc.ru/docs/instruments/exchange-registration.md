# Регистрация изменений для обмена

Инструмент для регистрации изменений объектов для обмена данными. Форк обработки с диска ИТС с адаптациями под подсистему.

## Возможности

- Регистрация изменений объектов
- Настройка правил регистрации
- Протокол регистрации
- Поддержка различных видов обмена

## Требования

- Платформа 1С: 8.3.12+
- Режим: Толстый клиент, Тонкий клиент
