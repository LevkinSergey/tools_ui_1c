# Совместимость с платформами

## Поддерживаемые версии

- **Минимальная:** 8.3.12
- **Рекомендуемая:** 8.3.15+
- **Тестовая:** 8.3.19.900

## Известные проблемы

| Проблема | Версии | Решение | Issue |
|----------|--------|---------|-------|
| Пустые конструкторы `ОписаниеОповещения` | 8.3.10 | Использовать `УИ_ОбщегоНазначенияКлиент.НовыйПустоеОписаниеОповещения()` | [#668](https://github.com/cpr1c/tools_ui_1c/issues/668) |
| Редактор JSON/HTML | < 8.3.14 (Windows) | Требуется платформа 8.3.14+ | - |
| Конструктор регулярных выражений | Все | Работает только в Windows | - |
| Web-клиент | Все | Некоторые инструменты работают частично | - |

## Рекомендации

### При разработке

1. Учитывайте минимальную версию 8.3.12
2. Избегайте синхронных вызовов
3. Не используйте модальность
4. Тестируйте на нескольких версиях платформы

### Проверка совместимости

```bsl
// Проверка версии платформы
Если ВерсияПлатформы() >= Версия("8.3.14") Тогда
    // Используем новые возможности
Иначе
    // Используем совместимый код
КонецЕсли;
```

## Тестирование

Обязательно тестируйте изменения на:

- Windows x86/x64
- Linux x64/x86
- Толстый клиент
- Тонкий клиент
- Web-клиент (частично)
