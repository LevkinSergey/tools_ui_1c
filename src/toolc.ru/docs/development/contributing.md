# Внесите вклад в проект

Больше идей — лучше конечное решение!

Проект развивается благодаря сообществу. Вы можете помочь следующими способами:

## 1. Писать код 💻

Вносить изменения и добавлять новую функциональность.

- [Инструкция для EDT](/docs/development/edt-setup)
- [Инструкция для Конфигуратора](/docs/development/configurator-setup)

### Процесс внесения изменений

1. Найдите или создайте задачу в [issues](https://github.com/cpr1c/tools_ui_1c/issues)
2. Сделайте fork проекта
3. Создайте ветку от `develop`
4. Выполните доработки
5. Создайте pull request в ветку `develop`

## 2. Документация 📖

Писать пользовательские инструкции, создавать видео.

- Обновлять существующие страницы
- Добавлять примеры использования
- Создавать видео-туториалы

## 3. Тестирование 🐛

Искать баги и регистрировать задачи с описанием воспроизведения.

- Тестировать новые версии
- Проверять работу на разных платформах
- Описывать найденные ошибки

## 4. Дизайн 🎨

Разрабатывать расположение визуальных элементов.

- Предлагать улучшения UI
- Создавать макеты форм
- Разрабатывать иконки

## 5. Поддержка 💬

Помогать другим пользователям в чате.

- [Telegram чат](https://t.me/tools_ui_1c)
- Ответы на вопросы в issues

## 6. Другое

Любые действия на развитие продукта.
