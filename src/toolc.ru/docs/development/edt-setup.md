# Настройка 1C:EDT

Среда разработки 1C:Enterprise Development Tool (EDT) рекомендуется для внесения изменений в проект.

## Необходимое ПО

### 1. JDK

**Версия:** Bellsoft JDK 11+ (рекомендуется 15.0.2+)

1. Скачайте с https://bellsoft.com/pages/downloads/
2. Установите
3. **Перезагрузите ПК**

### 2. 1С:Предприятие

**Версия:** 8.3.12+ с поддержкой EDT

- Рекомендуемая версия: 8.3.15+
- Тестовая версия: 8.3.19.900

### 3. 1С:EDT

**Версия:** 2020.5+ (рекомендуется 2021.1.2+)

1. Скачайте с https://edt.1c.ru/
2. Или используйте стартер EDT (ИТС → Дистрибутив 1C:EDT)

### 4. БСП

**Версия:** последняя с режимом совместимости 8.3.12

- Например: 3.0.3.341

## Пошаговая инструкция

### Шаг 1: Установка JDK

1. Скачайте JDK с сайта Bellsoft
2. Запустите установщик
3. Следуйте мастеру установки
4. Перезагрузите компьютер

### Шаг 2: Установка 1С

Установите платформу 8.3.12+ с поддержкой EDT.

### Шаг 3: Установка EDT

1. Запустите 1C:EDT Start
2. Авторизуйтесь на developer.1c.ru
3. Установите EDT 2020.5+

### Шаг 4: Настройка Git

Настройте Git согласно инструкции: https://its.1c.ru/db/edtdoc#content:10054:hdoc:t000054

**Базовые настройки:**

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"
git config --global core.autocrlf input
```

### Шаг 5: Создание fork

1. Перейдите на https://github.com/cpr1c/tools_ui_1c
2. Нажмите кнопку **Fork**
3. Склонируйте репозиторий:

```bash
git clone https://github.com/ВАШ_АККАУНТ/tools_ui_1c.git
cd tools_ui_1c
```

### Шаг 6: Создание тестовой базы

1. Запустите 1С:Предприятие в режиме Конфигуратора
2. Создайте новую базу из шаблона «Библиотека стандартных подсистем (демо)»
3. Откройте конфигурацию
4. Перейдите в раздел **Расширения**
5. Снимите **Активность** со всех расширений
6. Удалите расширения безвозвратно
7. Примените изменения
8. Закройте конфигуратор

### Шаг 7: Импорт в EDT

1. Откройте 1C:EDT Start
2. Авторизуйтесь на developer.1c.ru
3. Создайте новый проект:
   - Прикладное решение
   - Версия: 2021.1.2
   - Имя проекта: `tools_ui_1c`
4. Импортируйте из Git:
   - Выберите локальную папку с репозиторием
   - Нажмите **Далее** → **Готово**
5. Добавьте шаблон БСП в навигатор:
   - Имя проекта: **ТестоваяДляРазработкиУИ**
6. Дождитесь загрузки проекта
7. Обновите конфигурацию БД: **Shift+F7**

## Проверка настройки

1. Запустите проект в режиме отладки
2. Убедитесь, что все инструменты открываются
3. Проверьте работу хотя бы одного инструмента

## Правила разработки

- **Ветка:** все изменения вносятся в ветку `develop`
- **Табличные части:** нежелательно использовать в обработках (особенности сборки портативной версии)
- **Стандарты:** придерживаться стандартов разработки 1С (ИТС)
- **Лицензии:** для чужих обработок требуется разрешение автора или совместимая лицензия
- **Pull Request:** создавать в ветку `develop`, не `master`
