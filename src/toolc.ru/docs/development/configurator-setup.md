# Настройка Конфигуратора

Альтернативный способ разработки без использования EDT.

## Необходимое ПО

1. **1С:Предприятие:** 8.3.12+
2. **БСП:** последняя версия с режимом совместимости 8.3.12

## Инструкция

### Шаг 1: Скачайте релиз

Возьмите файл `UI.cfe` из [актуального релиза](https://github.com/cpr1c/tools_ui_1c/releases/latest).

### Шаг 2: Подключите расширение

1. Откройте конфигурацию БСП в Конфигураторе
2. Перейдите в меню **Расширения** → **Добавить**
3. Выберите файл `UI.cfe`
4. Обновите конфигурацию базы данных

### Шаг 3: Внесите изменения

Выполните необходимые доработки в режиме Конфигуратора.

### Шаг 4: Отправьте файл

Приложите доработанный файл `.cfe` к задаче в GitHub:

1. Откройте issue, который реализовывали
2. Перетащите файл в комментарий
3. Отправьте комментарий

## Ограничения

- Нет контроля версий на уровне модулей
- Сложнее отслеживать изменения
- Рекомендуется для разовых доработок

## Рекомендации

Для постоянной разработки рекомендуется использовать [EDT](/docs/development/edt-setup).
