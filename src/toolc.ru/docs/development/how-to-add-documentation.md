# Руководство по добавлению документации

Это руководство предназначено для новичков, которые хотят внести изменения в документацию проекта, но не имеют опыта программирования. Все изменения делаются через создание и редактирование текстовых файлов в формате Markdown (`.md`).

:::info Что такое Markdown?

**Markdown** — это простой формат разметки текста. Вы можете использовать:

- `# Заголовок` — для заголовков
- `**жирный текст**` — для выделения
- `[ссылка](url)` — для ссылок
- Обычный текст — для абзацев

Ничего сложного!
:::

## 📁 Структура проекта

Все файлы документации находятся в папке:

```
src/toolc.ru/docs/
```

Внутри этой папки есть тематические разделы:

```
docs/
├── intro.md                    # Главная страница введения
├── api/                        # Документация API
├── changelog/                  # История изменений
├── development/                # Документация для разработчиков
├── instruments/                # Описание инструментов
└── integration/                # Интеграция с другими системами
```

## 📌 Как добавить новую инструкцию в существующий раздел

### Шаг 1: Откройте папку с документацией

Перейдите в каталог `src/toolc.ru/docs/` и выберите нужный раздел.

**Пример:** Хотите добавить новый инструмент в раздел «Инструменты»? Откройте папку `instruments/`:

```
src/toolc.ru/docs/instruments/
```

:::note Примечание

Вы должны увидеть список файлов документации. Каждый файл `.md` — это отдельная страница документации.

:::

:::

### Шаг 2: Создайте новый файл

В папке раздела создайте новый файл с расширением `.md`.

**Правила именования:**

- Используйте английские буквы
- Слова разделяйте дефисом (`-`)
- Называйте файл по теме инструкции

**Примеры:**

- `my-new-tool.md` ✅
- `МойНовыйИнструмент.md` ❌
- `my_new_tool.md` ❌
- `my-new-tool-123.md` ✅

:::tip Совет

В VS Code или другом редакторе просто нажмите правой кнопкой мыши → «Создать файл» и введите имя.

:::

:::info Скриншот 2

> _Здесь будет скриншот создания нового файла в редакторе_

:::

### Шаг 3: Добавьте заголовок файла

В начале файла обязательно укажите специальную шапку (frontmatter). Она выглядит так:

```markdown
---
sidebar_position: 10
title: Мой новый инструмент
description: Краткое описание инструмента (1-2 предложения)
---

# Заголовок страницы

Основной текст документации...
```

**Разберем по строкам:**

| Поле               | Описание                                             | Пример                    |
| ------------------ | ---------------------------------------------------- | ------------------------- |
| `sidebar_position` | Позиция в меню (чем меньше число, тем выше в списке) | `1`, `5`, `10`            |
| `title`            | Заголовок в меню и на странице                       | `Мой новый инструмент`    |
| `description`      | Краткое описание для поисковиков                     | `Описание инструмента...` |

:::info Скриншот 3

> _Здесь будет скриншот примера frontmatter в редакторе_

:::

:::important Важно

- Шапка **обязательна**! Без неё страница не отобразится в меню.
- Между шапкой и заголовком должен быть пустой абзац.
- Заголовок первого уровня (`#`) должен быть один на странице.

:::

### Шаг 4: Напишите содержание

После шапки напишите основной текст. Используйте разметку Markdown:

````markdown
# Мой новый инструмент

Краткое описание инструмента.

## Возможности

- Возможность 1
- Возможность 2
- Возможность 3

## Как использовать

1. Откройте инструмент
2. Выберите нужный параметр
3. Нажмите кнопку «Выполнить»

## Примеры

Пример использования инструмента:

```bsl
Переменная = "Значение";
```
````

## См. также

- [Консоль запросов](/docs/instruments/console-requests)
- [Обзор всех инструментов](/docs/instruments/overview)

````

:::

### Шаг 5: Добавьте файл в меню (sidebar)

Откройте файл `src/toolc.ru/sidebars.ts` — это файл настройки бокового меню.

Найдите нужный раздел и добавьте имя вашего файла (без расширения `.md`):

```typescript
{
  type: 'category',
  label: 'Инструменты',
  items: [
    'instruments/overview',
    'instruments/my-new-tool',  // ← Добавьте эту строку
    // ... другие файлы
  ],
}
````

:::info Скриншот 5

> _Здесь будет скриншот редактирования файла sidebars.ts_

:::

:::note Примечание

- Путь указывается относительно папки `docs/`
- Без расширения `.md`
- В кавычках и с запятой в конце

:::

### Шаг 6: Проверьте результат

Запустите локальный сервер разработки:

```bash
cd src/toolc.ru
npm run start
```

Откройте браузер по адресу `http://localhost:3000` и проверьте:

1. Появилась ли страница в меню
2. Корректно ли отображается содержимое
3. Работают ли ссылки

## 📂 Как добавить новый раздел (категорию)

Новый раздел нужен, когда вы хотите сгруппировать несколько инструкций по общей теме.

### Шаг 1: Создайте папку раздела

В папке `src/toolc.ru/docs/` создайте новую папку с названием раздела.

**Правила именования:**

- Только английские буквы
- Слова через дефис

**Пример:**

```
src/toolc.ru/docs/tutorials/
```

:::info Скриншот 7

:::

### Шаг 2: Создайте файлы инструкций в разделе

Внутри новой папки создайте файлы документации, как описано [выше](#шаг-1-откройте-папку-с-документацией).

**Пример структуры:**

```
docs/tutorials/
├── beginner-guide.md
├── advanced-tips.md
└── best-practices.md
```

:::info Скриншот 8

> _Здесь будет скриншот файлов внутри нового раздела_

:::

### Шаг 3: Добавьте раздел в меню

Откройте файл `src/toolc.ru/sidebars.ts` и добавьте новую категорию:

```typescript
const sidebars: SidebarsConfig = {
  tutorialSidebar: [
    "intro",

    // Новый раздел
    {
      type: "category",
      label: "Обучающие материалы",
      items: [
        "tutorials/beginner-guide",
        "tutorials/advanced-tips",
        "tutorials/best-practices",
      ],
    },

    // Другие разделы...
  ],
};
```

:::info Скриншот 9

> _Здесь будет скриншот добавления категории в sidebar_

:::

**Разберем структуру:**

| Элемент            | Описание                              |
| ------------------ | ------------------------------------- |
| `type: 'category'` | Указывает, что это раздел (категория) |
| `label`            | Название раздела в меню               |
| `items`            | Список файлов внутри раздела          |

:::tip Совет

Размещайте новый раздел в том месте списка, где он будет логично смотреться. Порядок элементов в `items` определяет порядок в меню.

:::

### Шаг 4: Проверьте результат

Запустите сервер и убедитесь, что раздел появился в меню:

```bash
npm run start
```

## ✏️ Как изменить существующую инструкцию

### Шаг 1: Найдите файл инструкции

Определите, в каком разделе находится нужная инструкция, и откройте соответствующий `.md` файл.

**Пример:** Хотите изменить описание «Консоли запросов»? Откройте:

```
src/toolc.ru/docs/instruments/console-requests.md
```

:::info Скриншот 11

> _Здесь будет скриншот поиска файла инструкции_

:::

### Шаг 2: Внесите изменения

Откройте файл в текстовом редакторе и отредактируйте содержимое.

**Что можно менять:**

- Текст описания
- Примеры кода
- Скриншоты
- Заголовки
- Структуру разделов

**Что менять осторожно:**

- `sidebar_position` — влияет на порядок в меню
- `title` — название в меню и на странице
- Ссылки на другие страницы

:::info Скриншот 12

> _Здесь будет скриншот редактирования файла инструкции_

:::note Пример изменения

**Было:**


**Стало:**

```markdown
## Возможности

- Базовая функциональность

```

### Шаг 3: Добавьте скриншот (если нужно)

Если инструкция требует иллюстрации:

1. Положите файл изображения в папку `src/toolc.ru/static/img/`
2. Создайте подпапку по теме (например, `docs-guide/`)
3. В документации ссылайтесь так:

```markdown
![Описание скриншота](/img/docs-guide/my-screenshot.png)
```

:::important Требования к скриншотам

- **Формат**: PNG или JPG
- **Имя файла**: английские буквы, дефисы
- **Размер**: не более 500 КБ (по возможности)
- **Описание**: обязательно заполняйте альтернативный текст в `![...]`

:::

### Шаг 4: Проверьте изменения

Запустите локальный сервер и откройте измененную страницу:

```bash
npm run start
```

Убедитесь, что:

- Изменения отображаются корректно
- Нет битых ссылок
- Скриншоты загружаются

## ❓ Частые вопросы

### Я сохранил файл, но на сайте ничего не изменилось

Убедитесь, что запущен локальный сервер (`npm run start`). Docusaurus автоматически обновляет страницу при сохранении файла.

### Страница не появляется в меню

Проверьте:

1. Наличие шапки (frontmatter) в начале файла
2. Правильность пути в `sidebars.ts`
3. Отсутствие опечаток в имени файла

### Можно ли использовать русские имена файлов?

Технически можно, но **не рекомендуется**. Используйте английские имена с дефисами для лучшей совместимости.

### Как добавить таблицу?

Используйте синтаксис Markdown:

```markdown
| Заголовок 1 | Заголовок 2 |
| ----------- | ----------- |
| Ячейка 1    | Ячейка 2    |
| Ячейка 3    | Ячейка 4    |
```

### Как вставить код с подсветкой?

Используйте тройные кавычки с указанием языка:

````markdown
```bsl
Переменная = "Значение";
```
````
