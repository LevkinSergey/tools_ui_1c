# SEO-гайд для авторов документации

Это руководство поможет вам создавать документацию, которая будет хорошо ранжироваться в поисковых системах Google и Яндекс.

## 📋 Чек-лист перед публикацией

Перед тем как опубликовать новую страницу, проверьте:

- [ ] Есть `description` в frontmatter (150-160 символов)
- [ ] Есть `keywords` в frontmatter (5-10 ключевых слов)
- [ ] Заголовок H1 содержит ключевой запрос
- [ ] Есть хотя бы 2-3 подзаголовка H2/H3
- [ ] Текст разбит на абзацы по 3-5 строк
- [ ] Есть списки (маркированные или нумерованные)
- [ ] Добавлены внутренние ссылки на другие страницы
- [ ] Есть внешние ссылки на авторитетные источники
- [ ] Код оформлен в блоки с подсветкой синтаксиса
- [ ] Изображения имеют альтернативный текст (alt)

---

## 🏗️ Структура frontmatter

Каждый документ должен начинаться с frontmatter — блока метаданных в начале файла:

```markdown
---
sidebar_position: 10
title: Консоль запросов
description: "Разработка и выполнение запросов к базе данных 1С с подсветкой синтаксиса и анализом плана выполнения"
keywords:
  - консоль запросов 1С
  - выполнение запросов 1С
  - отладка запросов
  - 1С разработка
---
```

### Поля frontmatter

| Поле               | Описание              | Требования         | Пример                                  |
| ------------------ | --------------------- | ------------------ | --------------------------------------- |
| `sidebar_position` | Позиция в меню        | Число              | `10`                                    |
| `title`            | Заголовок страницы    | 50-60 символов     | `Консоль запросов`                      |
| `description`      | Описание для сниппета | 150-160 символов   | `"Разработка и выполнение запросов..."` |
| `keywords`         | Ключевые слова        | 5-10 слов (массив) | См. пример выше                         |

:::tip Совет

`description` должен быть уникальным для каждой страницы и содержать основные ключевые слова.

:::

## 🔑 Ключевые слова

### Как подобрать ключевые слова

1. **Основные запросы**: что ищут пользователи
   - "консоль запросов 1С"
   - "редактор JSON 1С"
   - "1С инструменты"

2. **Дополнительные запросы**: уточняющие слова
   - "бесплатно"
   - "скачать"
   - "как использовать"

3. **Long-tail запросы**: длинные фразы
   - "как выполнить запрос в 1С"
   - "редактирование JSON в 1С Предприятие"

### Где использовать ключевые слова

| Место              | Важность   | Частота  |
| ------------------ | ---------- | -------- |
| Заголовок H1       | ⭐⭐⭐⭐⭐ | 1 раз    |
| Первый абзац       | ⭐⭐⭐⭐⭐ | 1-2 раза |
| Подзаголовки H2/H3 | ⭐⭐⭐⭐   | 1-2 раза |
| Основной текст     | ⭐⭐⭐     | 3-5 раз  |
| Alt изображений    | ⭐⭐⭐     | 1 раз    |
| Ссылки (anchor)    | ⭐⭐⭐     | 1-2 раза |

:::warning Важно

Не злоупотребляйте ключевыми словами! Оптимальная плотность — 2-4% от общего объема текста.

:::

## 📝 Структура статьи

### Рекомендуемая структура

```markdown
# Заголовок H1 (основной запрос)

Краткое введение (2-3 предложения). Содержит основной ключевой запрос.

## Возможности

- Преимущество 1
- Преимущество 2
- Преимущество 3

## Требования

Описание требований к системе.

## Использование

### Подзаголовок H3

Пошаговая инструкция.

## Примеры

Примеры кода с комментариями.

## Программный интерфейс

Описание API.

## Известные ограничения

Честное описание ограничений.

## См. также

- [Ссылка 1](/docs/...)
- [Ссылка 2](/docs/...)
```

### Заголовки

| Уровень | Синтаксис        | Когда использовать                |
| ------- | ---------------- | --------------------------------- |
| H1      | `# Заголовок`    | Один на страницу, основной запрос |
| H2      | `## Заголовок`   | Основные разделы статьи           |
| H3      | `### Заголовок`  | Подразделы внутри H2              |
| H4      | `#### Заголовок` | Детализация внутри H3             |

## 🔗 Внутренняя перелинковка

### Зачем нужны внутренние ссылки

- Улучшают навигацию по сайту
- Распределяют вес между страницами
- Увеличивают время на сайте
- Помогают поисковикам индексировать контент

### Как добавлять ссылки

```markdown
Правильно:

- Подробнее в [документации API](/docs/api/overview)
- См. [Консоль запросов](/docs/instruments/console-requests)

Неправильно:

- Нажмите [здесь](/docs/...)
- Ссылка: /docs/...
```

### Рекомендации

- Добавляйте 3-5 внутренних ссылок на страницу
- Используйте релевантные анкоры (текст ссылки)
- Ссылайтесь на связанные темы

## 🖼️ Оптимизация изображений

### Требования к изображениям

| Параметр  | Значение                         |
| --------- | -------------------------------- |
| Формат    | PNG для скриншотов, SVG для схем |
| Размер    | до 200 КБ                        |
| Alt текст | 5-15 слов с ключевыми словами    |
| Имя файла | английские буквы, дефисы         |

### Пример

```markdown
Правильно:
![Консоль запросов 1С — интерфейс выполнения запроса с подсветкой синтаксиса](/img/console-requests-interface.png)

Неправильно:
![скриншот 1](/img/1.png)
```

## 📊 Мета-теги для социальных сетей

При публикации ссылки в социальных сетях автоматически подтягиваются:

- **Заголовок**: из `title` страницы
- **Описание**: из `description` страницы
- **Изображение**: `img/og-image.svg`

### Пример для Twitter

```
Универсальные инструменты 1С — 30+ инструментов для разработчика
Консоль запросов, редакторы JSON/HTML/СКД, групповая обработка...
🔧 Консоль запросов • 📊 Редактор СКД • 💻 Консоль кода
toolc.ru
```

## 🎯 Оптимизация для разных поисковиков

### Google

- Любит подробный контент (1000+ слов)
- Важны внутренние ссылки
- Ценит актуальность (показывайте дату обновления)
- Учитывает поведенческие факторы

### Яндекс

- Обращает внимание на ключевые слова в title
- Важна структура текста (заголовки, списки)
- Учитывает регион (указывайте ru-RU)
- Ценит уникальность контента

## 🚀 Быстрые победы

### Что сделать прямо сейчас

1. **Добавьте description** на все страницы без него
2. **Исправьте дубли title** — каждый должен быть уникальным
3. **Добавьте внутренние ссылки** между связанными статьями
4. **Оптимизируйте изображения** — сожмите большие файлы
5. **Проверьте мобильную версию** — сайт должен быть адаптивным

### План на месяц

1. Провести полный аудит контента
2. Оптимизировать топ-10 страниц по трафику
3. Добавить структурированные данные (Schema.org)
4. Настроить Google Search Console и Яндекс.Вебмастер
5. Создать контент-план на основе ключевых слов

## ❓ Частые вопросы

### Как долго ждать результатов SEO?

Обычно первые результаты видны через 2-4 недели. Полная оптимизация занимает 3-6 месяцев.

### Нужно ли писать по 1000 слов на страницу?

Нет, главное — полнота ответа на вопрос пользователя. Короткие статьи (300-500 слов) тоже ранжируются, если они качественные.

### Как часто обновлять контент?

Рекомендуется обновлять документацию раз в 1-3 месяца. Поисковики ценят свежий контент.

### Можно ли копировать описание из 1С ИТС?

Нет, это дублированный контент. Пишите уникальные описания своими словами.
