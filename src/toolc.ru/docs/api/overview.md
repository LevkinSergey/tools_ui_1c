# Программный интерфейс

Проект предоставляет программный интерфейс для использования в ваших обработках и расширениях.

## Доступные модули

### УИ_КоннекторHTTP

HTTP-клиент в стиле Python Requests.

```bsl
Результат = КоннекторHTTP.GetJson("https://api.github.com/events");
```

[Подробнее](/docs/instruments/connector)

### УИ_ПреобразованиеДанныхJSON

Библиотека сериализации данных 1С.

```bsl
Сериализатор = Обработки.УИ_ПреобразованиеДанныхJSON.Создать();
Структура = Сериализатор.ЗначениеВСтруктуру(Данные);
JSON = Сериализатор.ЗаписатьОписаниеОбъектаВJSON(Структура);
```

[Подробнее](/docs/instruments/serialization-lib)

### УИ_БуферОбменаКлиент

Работа с буфером обмена операционной системы.

```bsl
УИ_БуферОбменаКлиент.КопироватьСтрокуВБуфер("Моя строка");
```

### УИ_РегулярныеВыраженияКлиентСервер

Работа с регулярными выражениями.

```bsl
УИ_РегулярныеВыраженияКлиентСервер.Совпадает(
    "Hello world", 
    "([A-Za-z]+)\s+([a-z]+)"
); // Истина
```

[Подробнее](/docs/instruments/regex-builder)

## Методы отладки

### Отладка объектов

Используйте функцию `УИ_._От(Объект, Параметры...)` в форме вычисления выражения.

```bsl
УИ_._От(Запрос, "Мой запрос")
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД)
```

[Подробнее](/docs/api/debug-api)

### Сохранение в файлы

```bsl
УИ_._ОтФ(Объект, Параметры...)
```

Данные сохраняются во временный каталог на сервере.
