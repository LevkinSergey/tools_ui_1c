# Отладка объектов

Механизм отладки позволяет быстро открыть объект в соответствующем инструменте для анализа и редактирования.

## Вызов отладки

Используйте функцию `УИ_._От(Объект, Параметры...)` в форме вычисления выражения.

**Сигнатура:**

```bsl
Процедура _От(
    ОбъектОтладки,
    Параметр2 = Неопределено,
    Параметр3 = Неопределено,
    Параметр4 = Неопределено,
    Параметр5 = Неопределено
)
```

## Поддерживаемые типы объектов

### Запрос

Открывает [Консоль запросов](/docs/instruments/console-requests) с текстом запроса.

```bsl
// Базовый вызов
УИ_._От(Запрос)

// С наименованием
УИ_._От(Запрос, "Мой запрос")
```

### Менеджер временных таблиц

Открывает Консоль запросов с заполненными таблицами из менеджера.

```bsl
УИ_._От(Запрос.МенеджерВременныхТаблиц)
```

### Схема компоновки данных

Открывает [Консоль отчетов](/docs/instruments/console-reports) с СКД.

```bsl
// С настройками по умолчанию
УИ_._От(СхемаКомпоновкиДанных)

// С настройками
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД)

// С внешними наборами данных
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, ВнешниеНаборыДанных)

// С менеджером временных таблиц
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, ВнешниеНаборы, МенеджерВременныхТаблиц)

// С наименованием
УИ_._От(СхемаКомпоновкиДанных, НастройкиСКД, , , "Отчет по остаткам")
```

### Таблица формы

Получает схему компоновки и настройки динамического списка.

```bsl
УИ_._От(Элементы.Список, "Список заказов")
```

### Ссылочный объект базы

Открывает [Редактор реквизитов объекта](/docs/instruments/object-editor).

```bsl
УИ_._От(СсылкаНаОбъектБД)
```

### HTTP Запрос

Открывает [Консоль HTTP запросов](/docs/instruments/http-console).

```bsl
УИ_._От(HTTPЗапрос, СоединениеHTTP, "Получение задач")
```

## Логика работы

### Толстый клиент

Форма консоли открывается сразу по окончании выполнения вызова.

### Сервер, тонкий или веб-клиент

Информация сохраняется в справочник `ДанныеДляОтладки`. Вызов отладки происходит потом из списка справочника.

## Сохранение в файлы

Для сохранения данных отладки в файлы используйте метод `УИ_._ОтФ`:

```bsl
УИ_._ОтФ(Запрос, "Мой запрос")
```

Данные сохраняются во временный каталог на сервере.

## Примеры использования

### Отладка запроса из формы

```bsl
&НаКлиенте
Процедура ОбработкаЗапроса()
    Запрос = Новый Запрос;
    Запрос.Текст = "ВЫБРАТЬ * ИЗ Справочник.Номенклатура";
    
    // Отладка
    УИ_._От(Запрос, "Запрос номенклатуры");
КонецПроцедуры
```

### Отладка СКД

```bsl
&НаКлиенте
Процедура ОткрытьКонсольОтчетов()
    Схема = КомпоновщикНастроек.СхемаКомпоновкиДанных;
    Настройки = КомпоновщикНастроек.Настройки;
    
    УИ_._От(Схема, Настройки, , , "Отчет по продажам");
КонецПроцедуры
```
